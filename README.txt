SH AI 트레저헌터 1.0 (기존 SH 추리 챌린지와 독립)

포함: index.html 학생용, admin.html 관리자용, server.js 서버, missions.json 미션 설정, package.json

배포: 별도 GitHub 저장소를 만들고 이 파일들을 업로드합니다. Render에서 새 Web Service를 생성해 해당 저장소를 연결합니다. Start Command: npm start. 환경변수 ADMIN_PIN을 반드시 설정하세요.

학생용 주소: https://새로운-Render-주소/
관리자 주소: https://새로운-Render-주소/admin.html

기능: 40개 팀 등록, 8개 자유 탐색 미션(8번은 1~7 완료 후 잠금 해제), 정답 자동 채점, 현장 지도자 승인, 팀별/전체 초기화, 장소 변경, CSV 다운로드.

중요: 1/4/6번 미션 정답과 2번 암호는 시범값입니다. 현장에 맞게 missions.json을 수정하세요. QR 카메라 스캔/QR 코드 자동 생성은 아직 미구현이며 현장 암호 입력 방식입니다. AI API 연동도 미구현입니다.

데이터 보존: 기본 treasure-data.json은 서버 디스크에 저장됩니다. Render의 임시 파일시스템에서는 재배포/재시작 때 데이터가 유실될 수 있습니다. 실제 행사 전 영구 디스크 또는 외부 DB를 구성하세요. DATA_FILE 환경변수로 영구 디스크 경로를 지정할 수 있습니다.

안전: 관리자 PIN은 학생들에게 공유하지 마세요. 관리자 PIN을 바꾸면 관리자 화면에 새 PIN을 입력해야 합니다. 실전 운영 전 충분한 인원과 현장 테스트가 필요합니다.

기존 추리 챌린지 저장소에 업로드하지 마세요. 별도 저장소와 별도 Render 서비스로 배포하세요.
